# QR-04: The Model Key Of The Server Is Never In The Repository, In A Log, Or In An Error

The language model key that the server holds is read from `.env`, is never committed to the repository, and appears in no log line and in no error shown to the learner.

- **Status:** Active
- **Characteristic:** Security
- **Sub-characteristic:** Confidentiality
- **Business importance:** Medium
- **Technical risk:** Low
- **Changed:**
  - The outcome covered only the repository and the error shown to the learner. The Customer explained that the requirement is about how the product handles the value it reads from `.env`: "you have to ensure that this value does not appear in any logs, and that it is not shown to the learner in any error" (Customer, [01:32:51](https://github.com/itpd-team-6/sentence-cards-generator-team-6/blob/main/reports/week-04/meeting-transcript.md)). The logs are now part of the outcome and of the measure.

## Scenario

### Source

The team member or self-hoster who sets the key, and the learner who uses the product.

### Stimulus

The product is configured with a model key and run, and the model returns an error, such as a refusal of the key, that the product logs and whose text a learner can see.

### Environment

The open-source repository of [`CON-06`](https://github.com/itpd-team-6/sentence-cards-generator-team-6/blob/main/docs/product-vision.md#con-06), where no key or private data may be committed, and the key is kept in `.env`.

### Artifact

The settings in `backend/app/config.py`, the `.env` file ignored by `.gitignore`, and the model client in `backend/app/llm.py`, with every place of the `backend` that logs or reports an error.

### Response

The product shall read the key from `.env` only, and neither a log line nor an error message shall contain it.

### Response Measure

The repository tracks no `.env` and no key value, and after a run in which the model refuses the request and the product fails, the log output of the `backend` and the error text a learner sees contain no part of the key, which a search of both for the key value finds zero times.
