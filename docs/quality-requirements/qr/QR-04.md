# QR-04: The Model Key Is Never In The Repository And Never Shown To The Learner

The language model key is read from `.env` and never committed to the repository or shown to the learner, even in an error.

- **Status:** Active
- **Characteristic:** Security
- **Sub-characteristic:** Confidentiality
- **Business importance:** Medium
- **Technical risk:** Low

## Scenario

### Source

The team member or self-hoster who sets the key, and the learner who uses the product.

### Stimulus

The product is configured with a model key and run, and the model returns an error whose text a learner can see.

### Environment

The open-source repository of [`CON-06`](https://github.com/itpd-team-6/sentence-cards-generator-team-6/blob/main/docs/product-vision.md#con-06), where no key or private data may be committed, and the key is kept in `.env`.

### Artifact

The settings in `backend/app/config.py`, the `.env` file ignored by `.gitignore`, and the model client in `backend/app/llm.py`.

### Response

The product shall read the key from `.env` only, and the error message it shows the learner shall not contain the key.

### Response Measure

The repository tracks no `.env` and no key value, and the error a learner sees when the model fails contains no part of the key.
