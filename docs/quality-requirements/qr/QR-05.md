# QR-05: The Retries For One Word Stay Within About Nineteen Seconds

When the language model does not answer for a word, the time the product spends repeating the request stays within about nineteen seconds, so the learner is not left waiting without end.

- **Status:** Active
- **Characteristic:** Performance Efficiency
- **Sub-characteristic:** Time Behaviour
- **Business importance:** Medium
- **Technical risk:** Low

## Scenario

### Source

The external language model, called by the `backend` through the endpoint set in `.env`.

### Stimulus

The model keeps failing with a status that says it is overloaded or down for now, so the product repeats the request for one word.

### Environment

A learner generates a card for a word while the model is unavailable for every attempt, so the product uses all of its repeats before it gives up.

### Artifact

The retry in `backend/app/llm.py`, with its waits of 1, 2, 4 and 8 seconds and a random time of up to 1 second before each repeat, as [`DEC-024`](https://github.com/itpd-team-6/sentence-cards-generator-team-6/blob/main/docs/decisions.md#dec-024) fixes them.

### Response

The product shall repeat the request for a word up to 5 requests in all and then stop, so the backoff waits do not grow without bound.

### Response Measure

The waits between the 5 requests for one word add up to 15 seconds of backoff plus up to 4 seconds of random time, so the product waits at most about 19 seconds for one word, not counting the time of the requests themselves.
