# FR-016: Record An Event For Each Step Of The Core Task

- **Status:** Active
- **Traces to:** [`US-13`](https://github.com/itpd-team-6/sentence-cards-generator-team-6/issues/208), [`TOS-03`](../../threshold-of-success.md#tos-03), [`ADR-007`](../../architecture/adr/ADR-007.md)
- **Containers:** `backend`

## Behavior

When the learner saves a text, the `backend` shall record the event `text_saved` with the fields that [the events](../../analytics.md#the-events) list.

When the learner asks for the cards of a text, the `backend` shall record the event `cards_generated` with the number of words asked, of cards made and of words the language model failed for.

When the learner answers a card, the `backend` shall record the event `card_answered` with the answer.

When the learner asks for a new sentence of a card, or edits the sentence of a card, the `backend` shall record the event `sentence_replaced`.

The `backend` shall give every event a `source`, which is `web`, `usability-test` or `smoke`, and `web` when the request does not say.

The `backend` shall identify the learner in an event only by a one-way hash of the library code.

The `backend` shall not send a text, a word, a sentence, a translation, an e-mail address, a name or the library code in an event.

When `ANALYTICS_ENABLED` is not true, the `backend` shall send no event.

The `backend` shall send an event without making the request of the learner wait for it.

When the analytics backend does not answer, the `backend` shall answer the learner as it does without analytics and shall drop the event.

## Acceptance Criteria

### AC-01

Given the analytics turned off, when the learner saves a text, then no event is sent.

Test: `backend/tests/test_analytics.py::test_nothing_is_sent_when_the_analytics_is_off`.

### AC-02

Given the analytics turned on, when the learner saves a text, then the event `text_saved` has the languages and the number of marked words, and has not the text or its words.

Test: `backend/tests/test_analytics.py::test_saving_a_text_records_text_saved_without_the_text`.

### AC-03

Given the analytics turned on, when the learner asks for the cards of a text, then the event `cards_generated` has the numbers of words asked, of cards made and of words failed.

Test: `backend/tests/test_analytics.py::test_asking_for_cards_records_cards_generated_with_the_counts`.

### AC-04

Given a card, when the learner answers it, then the event `card_answered` has the answer and no card identifier.

Test: `backend/tests/test_analytics.py::test_answering_a_card_records_card_answered_with_the_answer`.

### AC-05

Given a card, when the learner asks for a new sentence or edits the sentence, then the event `sentence_replaced` says which, and a change that is not a sentence records nothing.

Test: `backend/tests/test_analytics.py::test_a_new_sentence_and_an_edited_sentence_record_sentence_replaced`, `backend/tests/test_analytics.py::test_a_change_that_is_not_a_sentence_records_nothing` and `backend/tests/test_analytics.py::test_new_sentences_for_several_cards_record_one_event_with_the_count`.

### AC-06

Given a library code, when an event is sent, then the learner is the hash of the code and the code is not in the event.

Test: `backend/tests/test_analytics.py::test_the_learner_is_a_one_way_hash_of_the_library_code_not_the_code` and `backend/tests/test_analytics.py::test_a_request_without_a_library_code_is_the_default_learner`.

### AC-07

Given a request that says its source, when an event is sent, then the source is `smoke`, `usability-test` or `web`, and any other value is `web`.

Test: `backend/tests/test_analytics.py::test_the_source_is_web_unless_the_request_says_smoke_or_usability_test`.

### AC-08

Given an analytics backend that does not answer, when the learner makes a request, then the request is answered and the event is dropped.

Test: `backend/tests/test_analytics.py::test_a_failure_to_send_never_breaks_the_request`.

### AC-09

Given the settings of an environment, when an event is sent, then it goes to the JSON endpoint of the organization of that environment with the user of that environment.

Test: `backend/tests/test_analytics.py::test_the_event_goes_to_the_json_endpoint_of_the_organization_with_its_user`.

### AC-10

Given an analytics backend that is slow, when an event is sent, then the request of the learner does not wait for it.

Test: `backend/tests/test_analytics.py::test_sending_an_event_does_not_make_the_request_wait`.
