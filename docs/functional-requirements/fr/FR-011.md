# FR-011: Ask The Language Model From The Browser With The User's Own Key

- **Status:** Active
- **Traces to:** [`DEC-040`](../../decisions.md#dec-040), [`DEC-038`](../../decisions.md#dec-038), [`ADR-004`](../../architecture/adr/ADR-004.md)
- **Containers:** `frontend`, `backend`

## Behavior

When a user has set their own language model key, the product shall make the requests to the language model from the browser, and shall not send that key to the `backend`.

When the language model answers a request made from the browser, the product shall save the cards of the answer in the `backend`, and shall show them in the cards table as it does for a request made by the `backend`.

## Acceptance Criteria

### AC-01

Given a user who has set their own key, when sentences are asked for a marked word, then the browser sends the request to the language model with the key, and no request to the `backend` contains any part of the key.

Check: the network panel of the browser lists the request to the model and the requests to the `backend`, and a search of the requests to the `backend` for the key value finds nothing.

### AC-02

Given a user who has set their own key and whose request was answered, when the cards table is opened again after the page is reloaded, then the cards of the answer are in it.
