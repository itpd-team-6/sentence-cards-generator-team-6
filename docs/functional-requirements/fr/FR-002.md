# FR-002: Ask The Language Model Again When It Does Not Answer

- **Status:** Active
- **Traces to:** [`DEC-024`](../../decisions.md#dec-024), [`DEC-012`](../../decisions.md#dec-012), [`ADR-003`](../../architecture/adr/ADR-003.md)
- **Containers:** `backend`

## Behavior

When the language model does not answer for a word, the product shall repeat the request, up to 5 requests in all for that word.

The product shall wait 1, 2, 4 and 8 seconds between the requests, each wait plus a random time of up to 1 second.

The product shall not repeat a request whose error a new request cannot fix, such as a request the service refuses or an answer that cannot be read.

When the language model still does not answer, the product shall report the error with the reason the service gave, and shall never show the key.

## Acceptance Criteria

### AC-01

Given a model that does not answer for now, when a sentence is asked for, then the model is asked 5 times in all and then the error is raised.

Test: `backend/tests/test_llm.py::test_a_model_that_does_not_answer_for_now_is_asked_5_times_in_all_and_then_the_error_is_raised`.

### AC-02

Given a model that does not answer, when the product waits between requests, then the waits are 1, 2, 4 and 8 seconds plus a random time of up to 1 second.

Test: `backend/tests/test_llm.py::test_the_waits_between_requests_are_1_2_4_and_8_seconds_plus_a_random_time_of_up_to_1_second`.

### AC-03

Given a model that answers after failing, when a sentence is asked for, then it gives its sentence and is not asked again.

Test: `backend/tests/test_llm.py::test_a_model_that_answers_after_failing_gives_its_sentence_and_is_not_asked_again`.

### AC-04

Given an error that a new request cannot fix, when the model refuses, then the request is not repeated.

Test: `backend/tests/test_llm.py::test_an_error_that_a_new_request_cannot_fix_is_not_repeated`.

### AC-05

Given a service that gives a reason for its error, when the error is reported, then the message carries the reason and never the key.

Test: `backend/tests/test_llm.py::test_the_reason_the_service_gives_for_an_error_is_added_to_the_message` and `backend/tests/test_llm.py::test_a_long_reason_is_cut_and_the_key_is_never_shown`.
