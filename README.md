# Sentence cards generator

ITPD course project, **Team 6**.

An app that generates language-learning flashcards: the user uploads a text, selects words, and an LLM produces example sentences with translations in the user's known language and the target language.

> This project is a work in progress for the IT Product Development (ITPD) course at Innopolis University, 2026.
